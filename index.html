    파일이 정말 서버로 안 올라가나요?

    올라가지 않습니다. 이 페이지에는 파일을 어디론가 보내는 코드 자체가 없습니다. 선택한 PDF는 브라우저 메모리에서 읽어 브라우저 안에서 합치고, 결과도 브라우저가 직접 저장합니다. 확인하고 싶으면 페이지를 연 뒤 인터넷(와이파이)을 끄고 써 보세요. 그대로 동작합니다.

    화질이나 용량이 나빠지지 않나요?

    나빠지지 않습니다. 이 도구는 페이지를 다시 그리지 않고 원본 데이터를 그대로 옮깁니다. 글자는 글자로, 이미지는 원본 그대로 남아 복사·검색·선택이 됩니다. 결과 용량은 대략 원본을 더한 만큼이고, 안 쓰는 데이터가 정리되면서 오히려 조금 줄어드는 경우도 있습니다.

    암호가 걸린 PDF도 되나요?

    안 됩니다. 열 때 비밀번호를 묻는 PDF는 내용이 암호화되어 있어 그대로 옮길 수 없습니다. 해당 파일에 빨간 표시가 뜹니다. 원본을 만든 프로그램이나 뷰어에서 암호를 푼 사본으로 저장한 뒤 올려 주세요.

    몇 개까지, 얼마나 큰 파일까지 되나요?

    개수 제한은 두지 않았습니다. 다만 모든 파일을 메모리에 올려서 처리하기 때문에 기기 메모리가 한계입니다. PC라면 수백 MB도 무리 없고, 스마트폰에서는 합쳐서 100MB 안쪽을 권합니다. 너무 크면 브라우저 탭이 멈출 수 있습니다.

    목차·양식·서명은 어떻게 되나요?

    페이지 안의 글자·이미지·표·주석·하이퍼링크는 그대로 옮겨집니다. 다만 책갈피(목차), 입력 가능한 양식 필드의 동작, 전자서명은 유지되지 않습니다. 전자서명은 문서가 바뀌면 원래 깨지도록 만들어진 것이라 어떤 도구로 합쳐도 마찬가지입니다. 서명이 필요하면 합친 다음에 다시 서명하세요.

    페이지 칸은 어떻게 쓰나요?

    비워 두면 전체입니다. 1-3, 7, 10- 처럼 쉼표로 나눠 적고, 10- 은 10쪽부터 끝까지입니다. 12-1 처럼 큰 수를 먼저 적으면 그 구간이 거꾸로 들어갑니다. 홀 또는 짝 이라고만 써도 되고, 홀 1-20 처럼 범위와 같이 쓸 수도 있습니다.

    아이폰·안드로이드에서도 되나요?

    됩니다. 파일 선택을 누르면 파일 앱·구글 드라이브·다운로드 폴더에서 PDF를 고를 수 있습니다. 결과는 다운로드 폴더(아이폰은 파일 앱)에 저장됩니다. 다만 오래된 브라우저에서는 압축 해제 기능이 없어 동작하지 않을 수 있으니, 브라우저를 최신으로 올려 주세요.
